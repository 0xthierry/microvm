# Code of Conduct

This project is committed to a respectful, harassment-free community.

## Expected Behavior

- Be respectful in technical disagreement.
- Give constructive, evidence-based feedback.
- Assume good intent while holding a high technical bar.

## Unacceptable Behavior

- Harassment, hate speech, or personal attacks.
- Doxxing, threats, or sustained disruption.
- Bad-faith interactions meant to derail collaboration.

## Enforcement

Project maintainers may remove comments, reject contributions, or ban participants for violations.

If you experience or witness violations, report directly to project maintainers through a private channel on GitHub.
